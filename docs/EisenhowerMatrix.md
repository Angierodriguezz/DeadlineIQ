DeadlineIQ — Eisenhower Matrix

The Eisenhower Matrix helps determine which features should be included in the first version of DeadlineIQ and which can be added or removed later.

1. DO — MVP (Important and Urgent)

These features are essential for the first working version.

Allow users to add, edit, and delete assignments, exams, and tasks.

Store assignment information, including course, title, deadline, importance, and estimated workload.

Automatically prioritize assignments based on deadlines, importance, and estimated workload.

Display upcoming assignments in priority order.

2. SCHEDULE — Version 2.0+ (Important but Not Urgent)

These features would improve the application but are not necessary for the first version.

Add a weekly calendar view to visualize upcoming assignments.

Implement recurring assignments and automatic reminders.

Generate personalized weekly study schedules.

Develop a graphical user interface or web application.

3. DELEGATE — Use Existing Libraries (Not Important but Urgent)

Use existing Java libraries and utilities instead of implementing these functions from scratch.

Use Java's java.time library for date and deadline calculations.

Use Java's Comparator and sorting utilities to organize assignments.

Use Java's built-in file handling utilities to read and write CSV data.

4. DELETE — Cut These Features (Not Important and Not Urgent)

These features are outside the scope of the project.

Social features such as messaging and sharing assignments with friends.

An AI chatbot for answering academic questions.

Motivational quotes, unnecessary animations, and decorative features.

Complex grade predictions and performance analytics.

MVP Goal

The first version of DeadlineIQ will allow students to manage their academic tasks, save their information, and automatically identify which assignments they should prioritize.
