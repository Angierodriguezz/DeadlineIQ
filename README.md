DeadlineIQ

Project Overview

DeadlineIQ is a student productivity application designed to help university students organize assignments, exams, and deadlines. It helps students prioritize their academic workload based on deadlines, importance, and estimated time required for each task.

Problem

University students often struggle to keep track of assignments, exams, and deadlines across multiple courses. This makes it difficult to prioritize their work and manage their time effectively.

MVP Features (Version 1.0)

Add, edit, and delete assignments.

Store assignment details, including title, course, deadline, importance, and estimated workload.

Automatically prioritize tasks based on deadlines, importance, and estimated workload.

Display assignments in priority order.

Save and load assignments using a CSV file.

Tech Stack

Programming Language: Java

Libraries: java.time, java.util.ArrayList, java.util.Comparator, java.io, java.nio.file, java.util.Scanner

Data Storage: CSV file
